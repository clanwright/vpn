# Triage labels

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | Waiting for more information |
| ready-for-agent | ready-for-agent | Specified and ready for agent implementation |
| ready-for-human | ready-for-human | Human implementation or judgment needed |
| wontfix | wontfix | Will not be actioned |

Use these exact strings when a skill names a canonical role.
Category labels such as `bug` and `enhancement` are separate.

Readiness describes the task; it does not authorize deployment,
publication, or other protected operations.
